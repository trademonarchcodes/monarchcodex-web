
HOW TO FIX EMAIL ERROR: Failed to send a request to the Edge Function

1. Get free Resend API key:
   - Go to resend.com -> Sign up -> API Keys -> Create -> Copy key (re_...)

2. In your project root, create folder supabase/functions/send-email/ and put index.ts inside (from this zip)

3. Install Supabase CLI:
   npm install -g supabase
   supabase login
   supabase link --project-ref avaworleivncevaoqeny

4. Set secrets:
   supabase secrets set RESEND_API_KEY=re_YourKeyHere
   supabase secrets set FROM_EMAIL="Monarch Codex <no-reply@monarchcodex.com>"

5. Deploy:
   supabase functions deploy send-email --no-verify-jwt

6. Test in admin.html -> Email Sender -> to: trademonarchofficial@gmail.com

If you don't want to setup email now, admin still works for all other features (KYC, investments, withdrawals, balance adjust). Email is optional.

Also run fix_storage_rls.sql in Supabase SQL Editor to fix KYC upload error.
